- [x] Selection Sort
- [x] Insertion Sort
- [x] Bubble Sort
- [x] Búsqueda lineal
- [x] Búsqueda binaria

## Tecnologías

- .NET

## Objetivo

Practicar y documentar algoritmos fundamentales, comprendiendo su lógica y funcionamiento mediante implementaciones propias.
